# XForm 2.1 Fixture Corpus

This directory contains language-independent end-to-end fixtures for XForm 2.1.

These cases are intended as a target suite for implementation updates across all runtimes. They are independent of XSLT parity and focus directly on 2.1 language features.

Each case directory contains:

- `input.xml`
- `transform.xform`
- `expected.xml`
- `README.md`
